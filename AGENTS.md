# AGENTS.md

## Project
- **Name:** FreeTabletBenefit.com
- **Type:** Static SEO website
- **Focus:** Free tablet benefit options, Lifeline eligibility, EBT, Medicaid, provider tablet availability, required documents, and application guidance.

## Core Editorial Rules
- Do not use em dashes anywhere.
- Use a natural, human-written tone.
- Do not make fake government claims.
- Do not claim that everyone gets a free tablet.
- ACP ended on **June 1, 2024**.
- Lifeline is active, but it mainly provides service discounts.
- Tablet availability depends on provider, ZIP code, inventory, eligibility, and current terms.
- The website is informational only.
- The website is not a government agency.
- The website is not a Lifeline provider.
- The website is not an ACP provider.
- The website is not a tablet distributor.

## Technical and UX Rules
- Use semantic HTML.
- Use clean static HTML, CSS, and JS.
- Build mobile-first.
- Prioritize fast loading.
- Do not use external JS libraries unless they are truly necessary.
- Do not use placeholder filler text.
- Do not include fake testimonials.
- Do not include fake reviews.
- Do not include fake author claims.
- Avoid the word `free` in URL slugs where possible.

## SEO Rules
- Homepage targets these terms:
  - free tablet
  - free government tablet
  - free tablet from government
  - free government phone and tablet
- Supporting posts must strengthen and support homepage rankings.
- Every page must include:
  - `<title>`
  - meta description
  - canonical URL
  - Open Graph tags
  - schema where needed
- Allowed schema types (only when valid):
  - Organization
  - WebSite
  - WebPage
  - Article
  - BreadcrumbList
  - FAQPage
- Do not use Review schema.
- Do not use AggregateRating schema.
- Internal links must be natural, helpful, and contextually relevant.

## Definition of Done
A task is done only when all requirements below are met:
- Site builds without broken links.
- All pages have complete, non-placeholder content.
- All posts are at least 1000 words each.
- Each post includes 2 image placeholders with:
  - filename
  - alt text
  - title
  - width
  - height
- `sitemap` and `robots.txt` exist.
- No em dashes appear in any file.
- No placeholder content remains.

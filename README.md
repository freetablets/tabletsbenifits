# FreeTabletBenefit.com Static Site Base

This repository contains the base static architecture for FreeTabletBenefit.com.

## What is included

- Homepage at `index.html` with premium editorial layout.
- Support pages in `pages/`.
- Blog post templates in `posts/` and post hub at `posts/index.html`.
- Mobile first styles in `assets/css/style.css`.
- Lightweight navigation behavior in `assets/js/main.js`.
- Image prompt placeholder files in `assets/images/`.
- `robots.txt` and `sitemap.xml`.

## Design system

- Colors: soft navy, blue, teal, white, light gray, amber accent.
- Typography: strong sans serif stack using system fonts.
- No external JS libraries.

## Local preview

You can serve the folder with any static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Compliance notes

- Informational website only.
- Not a government agency.
- Not a Lifeline provider.
- Not an ACP provider.
- Not a tablet distributor.
- ACP ended on June 1, 2024.
- Lifeline is active and mainly provides service discounts.
- Tablet availability varies by provider, ZIP code, inventory, eligibility, and current terms.
